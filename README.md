# The Lena Book, draft v0.2

Черновик книги и справочника по языку Lena.

## Как открыть

```bash
mdbook serve --open
```

или собрать статическую HTML-книгу:

```bash
mdbook build
```

## Статус

Это рабочий черновик, а не финальная спецификация. Главы специально написаны так, чтобы их можно было править по мере уточнения языка.
